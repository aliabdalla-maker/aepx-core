# Voice coverage matrix

Read-aloud and dictation use the voices installed on the user's device. The console detects, per locale, which voices exist (`web/lib/voice.ts`, unit-tested mapping for en, tl/fil, no/nb, zh-Hans, and 'none' for sat) and says so when none is available. No locale has been verified on a real device yet: that needs a device test pass (VOC-10). Audio download is not offered (speech synthesis output cannot be captured and device voices carry their own licences). Output-device selection is not possible for browser speech synthesis; the console reports the system default.
