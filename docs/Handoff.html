1. What This Document Is

This is the handoff package — the document that turns the ADLC Plan from a strategy artifact into a piece of work someone can start on Monday morning. It answers four questions for whoever is picking this up (a founding engineer, a contracted team, or the founder themselves):

  1. What exactly are we committing to build first? (§2 — a narrower, fundable scope than the full manual)
  2. Who owns what? (§3 — RACI against the minimum viable team)
  3. What do I do, in order, starting today? (§4 — a Day 1–30 checklist with a check-off state that persists in this file)
  4. What must be decided or resourced before I can proceed? (§5 — the blockers that stop this plan from working as written)

The step-by-step technical instructions this checklist points to live in the companion Instructional Manual (PDF) — this document is the management/ownership layer on top of it.

3. Team & RACI

The manual specifies a 7-person Year-1 team. The Critical Evaluation flagged that £250k of grant/angel funding cannot carry 7 UK FTEs for 12 months (~£600–700k loaded cost) — so this handoff requires a decision before Week 1:

Option A — As specified in the manual

Founder/Chief Architect + 2 Backend Eng + AI Eng + DevOps Eng + QA Eng + Product Owner (7 people).

Requires ~£600–750k raised before Week 1, not just the £250k grant/angel target.

Option B — Recommended lean team Recommended

Founder/Chief Architect (full-stack) + 1 Backend Engineer + 1 part-time DevOps/QA contractor. 3 people, matched to the £250k Month-1–6 budget.

Cuts Month-6 milestone list accordingly — see §15.5 Rec #4 in the ADLC Plan.

The RACI below assumes Option B (lean team); if Option A is chosen, split the Founder/Architect row across the additional named hires.

5. Decisions & Blockers Before Week 1

These must be resolved before the Week 1 checklist can actually run — they are not optional footnotes:
  1. Team size & funding path (§3). Option A needs ~£600–750k in hand; Option B needs a founder willing to run Months 1–6 at 3-person scale. Silently defaulting to "7 people, £250k" is the single most likely cause of a Month-5 stall (ADLC Plan §15.2 #5).
  2. MCP positioning decision. Confirm the team accepts "complement MCP" as the go-to-market frame before writing any public messaging or RFC-0001 language that implies a competing protocol.
  3. Pilot customer identified. Week 4's "share with 1 pilot contact" needs a named target now — cold-starting this in Week 4 itself will slip the Alpha timeline.
  4. RFC scope discipline. Only RFC-0001–0005 are drafted in Weeks 1–2. RFC-0006–0010 (Governance, Safety, Economics, Marketplace, Certification) are explicitly out of scope until Month 3+ — do not let Week 1 balloon into drafting all ten.

7. Definition of Done — v0.0.1 / Alpha Gate

Full procedure in Instructional Manual Part 3. Summary criteria this handoff is accountable to:

  • Fresh clone → docker compose up → working demo agent in <10 minutes, timed and recorded.
  • Discovery/Registry <50ms, Memory <20ms, Gateway <100ms, on local benchmark (Manual §3.6).
  • 1 MCP tool call proxied successfully end-to-end.
  • 1 named pilot contact has seen a live demo.
  • Alpha Gate 5-gate review scheduled for Month 3 (Manual Part 3).
