# AEP-X Agentic IDE for VS Code

Opens the AEP-X Agentic IDE, a governed workspace where an agent crew plans your change, you approve each
step, and every decision is audited.

- **AEP-X: Open Agentic IDE** (also the rocket button in the status bar)
- **AEP-X: Plans and pricing**: 30-day free trial with ads, then £4.99/month for 95% fewer ads, or keep
  the free ad-supported plan

The extension reads no workspace files, stores no credentials and makes no network requests of its own.
Self-hosted deployments can set `aepx.ideUrl` (machine scope, HTTPS only).
