# Phase 2.4 — governed execution integration (draft, disabled)

The new `app.governed_worker.execute_next` connects a tenant-scoped fenced queue claim to a transactional token/cost reservation, a spawn-process hard deadline, conservative maximum-reservation settlement and atomic fenced result persistence. Cancellation now invalidates queued and leased jobs in the same database transaction. The existing MCP adapter requires exact single-use HITL approval and a configured HTTPS proxy.

**Default:** no automatic worker dispatch; `IDE_EXTERNAL_EXECUTION_ENABLED` and `IDE_GOVERNED_WORKER_ENABLED` must both be explicitly set to true. Additionally `IDE_EGRESS_GATEWAY_VERIFIED=true`, `IDE_PROVIDER_USAGE_RECONCILIATION_ENABLED=true`, `IDE_WORKER_MAX_TOKENS`, `IDE_WORKER_MAX_MICROUSD` and `IDE_WORKER_TIMEOUT_SECONDS` must be explicitly configured. These flags are operator attestations, not evidence of verified infrastructure.

**Release blockers:** This is not production-ready. The code does not provision an isolated network gateway, validate DNS pinning, provide a per-tenant credential vault or reconcile actual provider usage. A subprocess timeout does not cancel remote provider billing. Conservative full-envelope settlement prevents reusing reserved budget but can overcharge tenants and still cannot reconcile provider charges after process death. Crash recovery can leave reserved balances stranded; explicit reconciliation and repair are required. Worker leases last 60 seconds while subprocess timeout is at most 30 seconds, but long DB stalls and process scheduling can still expire leases. Worker processes must be launched under a restricted OS/container identity, with no shell/code execution and audited outbound destinations. The worker's provider path is text-only; MCP is not automatically invoked by this path. No exactly-once external side-effect guarantees.

**Tests:** unit fail-closed checks plus PostgreSQL cancellation/fencing and budget tests. Real multi-process concurrent claims, crash recovery, actual provider and gateway end-to-end tests remain outstanding. Keep PR #25 draft. Do not merge, deploy or enable external execution.
