# Phase 2.9 staging acceptance — NOT RELEASED

## Demonstrated
- A reference Docker Compose worker uses Linux `network_mode: none`, dropped capabilities, read-only filesystem, no-new-privileges and disabled external execution. It can demonstrate that direct provider/MCP sockets fail **in that container**.
- PostgreSQL integration test forks a real lease-holder subprocess, kills it with SIGKILL, expires the lease, quarantines the job and rejects the stale fenced result. This is a genuine leased worker crash but **does not cover all billing/provider transaction boundaries**.
- Signed mock receipts validate canonical payloads, tenant, tamper detection and duplicate reconciliation. The signature is generated by a local test key, not a third-party provider.
- OIDC principal + membership-gated owner/admin operations alerts; regression checks for absent bearer and unknown tenant.

## Must be demonstrated before production
1. Deploy an audited outbound gateway on a separate isolated network. Provider SDKs and MCP must have **no direct internet route** and be forced through the gateway. Verify actual SDK/MCP traffic, DNS rebinding, metadata access, redirects, IP literal bypass, proxy environment overrides and TLS/SNI pinning. `network_mode: none` alone cannot reach the gateway and is not a functioning production worker topology.
2. Obtain independent provider billing records and bind immutable request IDs to reserved spend. Verify replay and duplicate charge prevention across crashes and restarts.
3. Expand real SIGKILL tests to after budget reservation, immediately before/after provider dispatch and after settlement; audit each crash for no replay and correct reconciliation.
4. Test owner/admin/editor/viewer permissions and cross-tenant RLS on alerts, jobs, approvals and billing; inspect full repository CI and security scan.
5. Staging-only restore/rollback rehearsal with measured RTO/RPO, incident escalation, secrets revocation, security sign-off and a documented kill switch.

## Operator runbook
- Keep `IDE_EXTERNAL_EXECUTION_ENABLED=false` and MCP/worker flags disabled.
- For anomalous spend or provider response, revoke egress, quarantine expired leases, retain logs and provider receipts, and reconcile with an independently authorized operator.
- Do not automatically retry ambiguous external calls.
- Never merge PR #25 or deploy without a separate explicit release decision.
